# 🧮 SmartCalc

**SmartCalc** is a lightweight, interactive calculator built with Python, HTML, CSS, and JavaScript. It combines a modern browser-based calculator interface with a Python terminal calculator in one simple project.

Designed with a clean UI, interactive buttons, multiple themes, keyboard support, and calculation history, SmartCalc makes everyday calculations simple and enjoyable.

---

## ✨ Features

### 🖥️ Interactive Web Calculator
- Addition, subtraction, multiplication, and division
- Decimal number support
- Positive and negative numbers
- Modulo (remainder) operation
- Operator chaining
- Large number formatting with commas
- Error handling for division by zero

### 🎨 Modern User Interface
- Premium dark-themed design
- Glassmorphism-style calculator card
- Interactive button hover effects
- Click animations and ripple effects
- Responsive layout
- Three visual themes:
  - 🌑 Dark
  - 💡 Light
  - 🟣 Cyberpunk

### ⚡ Interactive Features
- Keyboard input support
- Enter key to calculate
- Escape key to reset
- Backspace to delete the last digit
- Copy result to clipboard
- Optional click sounds
- Calculation preview display

### 📜 Calculation History
- Automatically saves previous calculations
- Displays previous expressions and results
- Reuse previous results with a click
- Clear calculation history
- Stores history locally in the browser

### 🐍 Python Terminal Calculator
- Command-line calculator
- Addition, subtraction, multiplication, and division
- Input validation
- Division-by-zero protection
- Continuous calculation loop
- Simple menu-based launcher

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/swarupdhar011-sketch/Calculator.git```

### 2. Navigate to the project directory

```bash
cd Calculator```

### 3. Run the application

Make sure Python 3 is installed.

```bash
python main.py
```

### 4. Choose your calculator

The launcher provides the following options:

```text
====================================
       SMARTCALC LAUNCHER
====================================

1. Launch Interactive Website (Browser)
2. Run Terminal Calculator
3. Exit
```

- **Option 1:** Opens the interactive calculator in your default browser.
- **Option 2:** Starts
